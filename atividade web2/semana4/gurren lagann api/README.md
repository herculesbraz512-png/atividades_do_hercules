tema: Gurren Lagann

obijetivo: desenvolver uma api com Node.js e Express sobre os personagens
de anime Gurren Lagann.

como instala:
1) instale o Node.js
2) abra o terminal no projeto
3) execute: "npm install"

como iniciar: 
1) execute o comando
2) npm start
servidor funcionara em: http://localhost:3000

tecnologias utilizadas:
JavaScript
Node.js
Express
